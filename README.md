# maoyan-watch

猫眼影院新增排片监控。监控指定影院所有在 IMAX 厅放映的电影及其未来日期，发现新日期或加场后，通过飞书、钉钉自定义机器人发送合并通知。不执行选座、下单或支付。

## 环境

Python 3.9+，macOS 或 Linux（使用 `fcntl` 文件锁），仅依赖 Python 标准库。Linux 系统需安装时区数据库。

## 配置和运行

```sh
cp config.example.json config.local.json
chmod 600 config.local.json
```

编辑 `config.local.json`：飞书填写 `FEISHU_WEBHOOK`；钉钉填写 `DINGTALK_WEBHOOK` 和 `DINGTALK_SECRET`（SEC 开头的加签密钥）。至少配置一个渠道。也支持同名环境变量，环境变量优先。

真实配置仅留在本机，已被 `.gitignore` 排除。不要将机器人 URL、访问令牌或加签密钥填入源码、示例文件、Issue 或日志截图。

在 `watch.py` 顶部调整 `CINEMA_ID`、`CINEMA_URL`、`CINEMA_NAME`、`WANT_HALL`。默认监控前滩 MOViE MOViE 的所有 IMAX 厅电影，包括在 IMAX 厅放映的普通 2D 电影；不再限定片名。

```sh
python3 watch.py
```

后台运行：

```sh
nohup python3 -u watch.py >>runner.log 2>&1 &
echo $! > watch.pid
```

停止本次后台进程：

```sh
kill -INT "$(cat watch.pid)"
```

## 监控行为

- 第一次成功抓取为全部 IMAX 影片建立已有排片基线，不发送历史通知；之后持续检测新增影片、新日期及加场。升级时同样不补发当前已有排片。
- 按影院、影片 ID、日期、时间、影厅和版本去重，同名影片不会相互覆盖。
- SQLite 在事务中记录新增场次和通知队列，每个渠道分别确认送达。失败通知在后续成功抓取周期重试，即使场次已从接口消失也保留原通知；已成功渠道不重复发送。
- 同一影片同批新增场次合并，最多每 10 场一条；不同影片分别通知，各日期汇总时间，底部只留一个影院购票入口。
- 只发送放票消息。启动、心跳和异常不发群消息；异常及运行情况写入本地日志。
- 所有时段按北京时间：冲刺 20±5 秒、常规 60±20 秒、夜间 25±5 分钟；具体窗口见源码。
- 检测到风控时退避降级；发现时间是轮询首次观察时间，不代表影院精确发布时间。
- `monitor.sqlite3` 保存影片、上映信息、首次发现时间、历史场次及每个渠道的通知队列，请保留。第一次启动会幂等导入旧 `continuous_state.json` 历史，保留原文件且不重发旧通知。
- 数据库按影院/影厅隔离基线；新增渠道不会自动补发已经生成的旧通知。
- 请求已被服务端接收但响应丢失、或成功发送后写盘失败时，重试仍可能重复送达，不能保证严格恰好一次。
- 单进程文件锁防止同目录重复启动；机器休眠、断网或关闭后无法持续监控。

影院接口属于外部依赖，可能变化。请合理调整轮询频率并遵守平台使用规则。

## 测试


测试使用模拟数据和通知接口，不会向机器人发送消息。真实配置、排片状态、日志及旧备份不进入版本库。

## 新片和首映标记

影院排片接口没有完整上映日期，因此对有 IMAX 排片的影片查询猫眼影片详情，结果每部缓存 24 小时，失败也缓存以避免反复请求。优先使用详情中明确的中国大陆上映/重映日期；缺失时仅在没有地区说明的情况下采用 `rt`，来源保存在数据库中。无法确认时标记日期未知，不能将首次监测日期当成正式上映日期。

- 消息开头区分：新片首映放票、新片预售放票、新片首周放票、重映关注、首次监测到影片、普通新增放票。
- 正式上映前 7 天到前 1 天标记“上映前 N 天”；当天标记“首映日”；当天到第 7 天属于上映首周。
- 消息同时根据发现当天标记上映进度、根据每个观影日期标记首映场/首周场，提前一周发现首映排片也能识别。
- 重映使用单独标记，避免将老电影误报为新片。影片详情的上映日期仍可能被平台调整，标记不代表影院官方首映活动。
- 仅有新增场次才通知；进入上映前一周或首映日不会额外定时提醒，保持无心跳、无状态群消息。
- 升级前未监测的影片不能还原之前一周的首次放票时间；升级后会持续积累本地历史。

数据库表：`movies`（影片和上映来源）、`shows`（历史场次）、`outbox`（消息与送达时间）、`meta`（迁移和基线状态）。数据库、WAL/SHM 附属文件和真实配置均不提交到 Git。
